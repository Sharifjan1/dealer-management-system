# Dealer Management System

A full-stack dealership inventory and financial management system
built to help automotive dealers manage vehicles, expenses, and profits.

## Features

- VIN decoding
- Vehicle inventory management
- Purchase price tracking
- Vehicle expense tracking
- Total investment calculations
- Projected profit calculations
- ROI calculations
- Sold vehicle tracking

## Technology

- Python
- FastAPI
- SQLAlchemy
- React Native / Expo
- SQLite / PostgreSQL
